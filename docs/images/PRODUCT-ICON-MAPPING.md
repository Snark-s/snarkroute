# Product Icon Mapping

Product icon mapping for the two interfaces.

- `SnarkRoute.png`: used as the SnarkRoute Living Canvas icon in `apps/snarkroute/public/snarkroute-icon.png`.
- `SnarkRoute.ico`: generated from `SnarkRoute.png` and used by `START.lnk` and `SnarkRoute Living Canvas.lnk`.
- `ad7022ae-2c4b-4c89-a2b8-b660af5936ef.png`: used as the BoojumRoute Lab icon in `apps/studio/public/boojumroute-icon.png`.

The BoojumRoute source filename is not descriptive, so this file records the mapping used by the app assets.
