## Повторная проверка

В этом чате активен отдельный heartbeat Codex `claude-fl`, «Проверить результат
Claude на FL», с интервалом один час. Он только наблюдает за результатом;
владельцем бизнес-расписаний Бужи остаётся ChatGPT Automations.

Команда из `apps/server`:

```powershell
node --import tsx scripts/buzha-claude-result-check.ts
```

Скрипт сохраняет результат в
`apps/server/data/agent-ops/sandbox/buzha-claude-result-check/latest.json`,
а при изменении проверяемых фактов — также отдельный датированный снимок.
Отпечаток исключает время запроса и динамический HTML; повтор в 00:15 дал
`changed: false`, `candidateReady: false`, `modelCallsByThisCheck: 0`.

Heartbeat должен молчать при неизменном состоянии и сообщать только о
существенном изменении, подтверждённом завершении, ошибке или требуемом действии
владельца. При подтверждённом завершении он повторно проверяет результат,
сохраняет итоговый отчёт и приостанавливает только себя. Автоматически принимать
исходную задачу, запускать исполнителя, менять лимиты или публиковать ему запрещено.
