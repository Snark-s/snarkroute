## Найденные причины остановки

- После появления effects общий buildTaskPrompt требовал ручной POST резервации,
  недоступной в структурированном цикле Бужи. Её доверенные инструменты уже делали
  эту резервацию. Для actual executor buzha_* ручная инструкция теперь убрана;
  для остальных исполнителей сохранена. Автоматическая запись до действия,
  сверка после него и блокировка неизвестного исхода остаются обязательными.
- Описание browser_prepare_action не перечисляло root/path для upload. Модель
  передала только selector и получила Root not allowed. Оба аргумента теперь
  явно описаны и обязательны для подготовки и исполнения upload. Неполный
  запрос не доходит до моста и не резервирует действие. Центральные разрешения
  не менялись, модель не получает право выбирать дополнительные папки.
- Одна дополнительная попытка при 24/24 не даёт подписочному исполнителю шагов.
  Форма и повторное чтение текущего бюджета перед действием блокируют такой грант.

Контролируемый тест воспроизводил конфликт инструкций до исправления. После
исправления проверена последовательность reserve → dispatch → reconcile без
ручной резервации со стороны модели, а также сохранение ручного требования для
обычного CLI-исполнителя. Проверки upload подтверждают аргументы и транспорт;
это ещё не подтверждение настоящей загрузки файла после правки.

## Как был применён грант

Общая owner-only форма доступна в [Бужа](http://127.0.0.1:5172/buzha) и Диспетчере.
Она раскрыта сразу под счётчиками; читает текущую задачу, выделяет ровно одну
попытку штатным budget API, затем передаёт уточнение через resolve:continue.
Повтор уже сохранённого гранта 4/5 не выделяет шестую попытку. Ошибка budget API
не запускает продолжение. Если сессии владельца нет, интерфейс сообщает об этом
явно вместо ложного «поручений нет».

Автоматическая проверка ранее отклонила привязку Computer Use к нативному Chrome
из-за недостаточно надёжно определённого URL и риска доступа к неверной вкладке.
Поэтому грант применил сам владелец. Обход через CDP, browser storage, извлечение
owner credential или прямое редактирование файлов задач не применялся.
