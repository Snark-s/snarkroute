# Пятая попытка FL: разрешена, готова к запуску из Мастерской

Владелец явно ответил «Разрешаю пятую попытку» и сообщил о входе владельцем.
Новое согласие на попытку не требуется. Задача — прежняя
`t-20261029-58ccc5e2`; последняя подтверждённая история — 4/4 попытки и 15/24
подписочных шагов. Лимит 24 и использованные шаги сохраняются.

## Запуск в авторизованной сессии

1. Обновить [карточку Бужи](http://127.0.0.1:5172/buzha) в том Chrome, где выполнен вход владельца.
2. Найти `t-20261029-58ccc5e2` и раскрыть **«Разрешить одну дополнительную попытку»**.
3. Убедиться, что форма показывает 4/4, 15/24 и новый предел 5.
   Уточнение уже заполнено и доступно для правки.
4. Нажать **«Разрешить одну попытку и продолжить»**.

Это применение уже разрешённого решения. Форма заново читает текущую задачу,
вызывает штатный owner-only budget API только с `maxAttempts: 5`, затем
`resolve: continue` с текстом уточнения. Задача, счётчики, инструменты,
полномочия, общий подписочный бюджет и защита внешних действий прежние.
Если грант уже сохранён и осталось 4/5, форма продолжает с уточнением,
не выдавая шестую попытку. При ошибке budget API продолжение не вызывается.
Выполнение и независимая приёмка идут на сервере без открытого чата Codex.

Та же форма доступна всем агентам в общем Диспетчере; отдельного механизма
приёмки или повышения лимита только для Бужи нет.

## Граница проверки

Автоматическая проверка отклонила привязку Computer Use к нативному окну Chrome
«Мастерская» после прежней остановки из-за недостаточно надёжно определённого URL.
Причина — риск доступа к неверной или частной вкладке. Привязка не выполнена,
обход через CDP, browser storage, извлечение owner credential или прямое
редактирование файлов задач не применялся. Поэтому фактический серверный грант
и запуск пятой попытки ещё не подтверждены; форму должен нажать владелец в
своей уже авторизованной Мастерской.

Проверки: 5 тестов последовательности запросов и защиты от лишней попытки,
TypeScript и production-сборка launcher. Живая визуальная проверка в нативном
Chrome остановлена указанным отказом; готовность всего FL-профиля не заявляется.
