# MiniMax H3: реестр технических идей

Обновлено: 15 октября 2026 года.
Назначение: рабочий реестр идей для локального H3 backend / H3-worker в SnarkRoute. ComfyUI-решения считаются источниками технологий и экспериментов, а не требуемой архитектурой.

## Статусы
- **Экспериментально реализовано** — есть код/изменения по предыдущему обсуждению, реальной генерацией не подтверждены.
- **К исследованию** — идея или внешняя реализация известна, локальной интеграции не подтверждено.
- **Отложено** — зафиксировано, но не внедрять без отдельного решения.
- **Базовая архитектура** — ранее согласованное направление; текущее состояние требует проверки в репозитории.

| № | Идея | Суть / критерий проверки | Статус |
|---|---|---|---|
| 1 | Latent chaining | Хранить видео- и аудиолатенты сегментов, продолжать последовательность без промежуточного VAE encode/decode; склеивать латенты и декодировать в конце, исследовать тональный дрейф | Экспериментально реализовано по предыдущим сведениям: `h3_latent_archive.py`, `.safetensors`, `H3_LATENT_CAPTURE_DIR`; реальная генерация не подтверждена |
| 2 | Veda sparse attention | Headless integration в H3 runtime, `auto/veda/dense`, замер VRAM, времени, качества | К исследованию |
| 3 | PDD Acc | Parallel Decoding Distillation, сокращение количества шагов; сравнить качество и совместимость | К исследованию |
| 4 | MiniMax-H3-X2-Detail-VAE | Режим X2 Detail VAE с отдельным PixelShuffle-декодером и переключателем на обычный VAE | К исследованию |
| 5 | LBH / X2 Stream | Ускоренный видеопроход, сравнение скорости, качества и VRAM с базовым H3 на RTX 3080 Laptop 16 ГБ | К исследованию |
| 6 | AudioFirst X2 Stream | Разделять генерацию звука и видео: сначала аудиолатент, затем видеопроход с сохранённым аудио; сравнить речь и скорость | К исследованию; добавлено 15.10.2026 |
| 7 | Cinematic Realism LoRA | Кинематографические визуальные модификаторы, библиотека LoRA в H3 backend | К исследованию |
| 8 | Character Turnaround → 3D | Один референс → поворот персонажа в H3 → ракурсы/character sheet → реконструкция 3D | Отложено |
| 9 | H3 → Depth → Seedance | Получение глубины и пространственно-временного референса из H3 для последующей обработки | Отложено / к исследованию |
| 10 | H3 → 3D rig → animation | Из H3 получить последовательность для риггинга/анимации, проверить практическую ценность | Отложено |
| 11 | Snark Director / H3 Max | Управляемая режиссура потоковой генерации: промпты, жесты/MIDI, музыка, ключевые кадры; отдельно от локального H3 Base | Отложено / к исследованию |
| 12 | H3 backend без ComfyUI | H3 worker/API, headless-пайплайн, маршрутизация через SnarkRoute, а не зависимость от интерфейса ComfyUI | Базовая архитектура; фактическое состояние требует проверки |
| 13 | Turbo → Max → Base → 2K | Многоступенчатый пайплайн быстрых превью, уточнения и финализации; проверить реальную совместимость | К исследованию |
| 14 | Модели и режимы | Base local, Max hosted, Turbo experimental; выбор режима через единый backend abstraction | Базовая архитектура; фактическое состояние требует проверки |
