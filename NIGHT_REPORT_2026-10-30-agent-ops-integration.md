## 2. Что реализовано

За основу взята реализация Codex: Приёмщик, контракт, pause/resume/amend/effects, исполнение Бужи, `reviseBudget`,
`continueLease`, `runtimeVersion`. Моя конкурирующая приёмка удалена.

- **Учёт времени** — принят вариант Codex:
  - активное время — это попытки исполнителя (кроме тех, что только ждали ресурс) плюс `reviewRuns` Приёмщика;
  - ожидание учитывается в `task.waiting`.
  - Поверх добавлено:
    - `timeLeftMs` берёт минимум из трёх ограничений: собственный бюджет задачи (`activeMinutes`, иначе
      `wallMinutes`), бюджет цепочки и явный `deadline`;
    - возраст задачи от `createdAt` только показывается и ничего не блокирует;
    - этот минимум используется при запуске, для таймаута исполнителя и для таймера проверки.
- **Полномочия.**
  - Аноним может только читать.
  - Чужие задачи не читаются ни по HTTP, ни по MCP.
  - Heartbeat резерва принимается только от его владельца.
  - Origin, Referer и Host прав не дают.
- **Вход владельца.**
  - Одноразовый код от лаунчера: живёт 2 минуты, гасится один раз, хранится хэш, в журналы не попадает.
  - Код передаётся во фрагменте URL и стирается `replaceState`.
  - Сессии привязаны к эпохе; есть `revoke-all`.
- **Mixar и панели Adobe.** Их код не менялся. Вызов модели или GPU без токена сервер приписывает процессу по
  `netstat` и дереву родителей:
  - дерево агента — фоновая работа с режимами и резервами;
  - программа владельца — интерактивный клиент;
  - оборванная цепочка — неизвестный клиент, считается фоновой работой.
- **Занятость компьютера.** Решение принимается по измеренной нагрузке GPU, VRAM и CPU и по рендерам, а не по
  открытым окнам.
- **Квоты.** В ledger отдельно видны измеренное SnarkRoute, отчёт провайдера, внешнее использование и наши пределы.
- **Смоук-проверки** (сегодня):
  - Режим владельца больше не меняется. Задача паркуется за собственной тяжёлой арендой и ставится на паузу.
  - HTTP-вызовы идут от имени агента.
  - Скрипт Приёмщика подаёт поручение с токеном Бужи.
