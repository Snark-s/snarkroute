This repository uses a layered license structure.

## Source Code

This includes application code, package code, scripts, tests, and executable implementation files unless a file states otherwise.

## Open Route Protocol Specification

Open Route Protocol specification documents are licensed under CC BY-SA 4.0.

## Documentation

Documentation is licensed under CC BY-SA 4.0 unless otherwise stated.

## Example Routes And Example Node Manifests

Example route files and example node manifest documents are licensed under CC BY-SA 4.0 unless otherwise stated.

If a specific example is executable source code rather than a route/specification document, it is licensed under AGPL-3.0-or-later unless otherwise stated.

## Generated Outputs

Generated outputs are not automatically covered by the SnarkRoute source code license or the documentation/specification license.

Images, videos, text, files, and other results created by users through SnarkRoute belong to their creators/users, subject to the terms of the models, APIs, routes, nodepacks, and services used.

Third-party dependencies are governed by their own licenses.
