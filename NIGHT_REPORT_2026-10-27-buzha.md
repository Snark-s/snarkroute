# Бужа: интеграция в Мастерскую, 27.10.2026

Живая интеграция бюро учёта и чата выполнена. Бужа доступна через карточку
«Агенты» в Мастерской и `http://127.0.0.1:8796/`. Автономный исполнитель
не подключён; health сообщает `automation:false`.

Добавлены запись/путь в реестре, запуск `python server.py --no-browser`,
identity-проверенные start/stop/status/open, контроллер общего менеджера
процессов, терминал, общая кнопка «Остановить все задачи», публичная иконка.
Остановка использует собственный API и сессионный токен Бужи, не чужие PID.

Чат использует совместимый адаптер к действующему `ai.text` Model Gateway
SnarkRoute. Пользователь выбирает модель из каталога; видит справочные цены
и стоимость ответа. Выбор, стоимость, usage и provenance сохраняются в SQLite.
Код приложения не имеет provider URL/ключей и не повторяет модельный запрос
автоматически. Поддерживаются маршруты OpenRouter и local_openai с однократным
inference POST. Лимит ответа — 1024 выходных токена.

Проверено:

- TypeScript: 37 сфокусированных проверок (lifecycle, gateway, общая остановка,
  admission, системный каталог, MCP); Python: 5 проверок базы, реестра, чата
  и сессионной остановки. Проверка типов сервера и сборка лаунчера.
  Те же 37 TypeScript-тестов и типы сервера/лаунчера отдельно прошли на
  подготовленном Git tree без исходной незакоммиченной работы.
- Проверка реестра: порт 8796 свободен до регистрации; дублей нет.
- Живой `health`, реальные start/stop/open, повторный старт, карточка, иконка
  и наличие журнала в терминалах.
- Browser smoke в Chrome: создание заказа и ручного задания, выбор модели,
  сохранение всех трёх после остановки/нового процесса Python; все вкладки
  при ширинах 1440 и 390 px. Использовалась отдельная временная SQLite-база.
  Найденное переполнение мобильной навигации исправлено; скриншоты просмотрены.
- Реальный ответ через SnarkRoute: `cohere/north-mini-code:free`,
  `run_1793101614288`, provider/base cost `0 USD`, credits `0`.
  Ответ: «Бюро готово, автопоиск не подключён.» Модель выбрана из текущего
  каталога по нулевой цене; её идентификатор не зашит в код приложения.
- Первый модельный тест завершился сетевым connect timeout. После бесплатной
  проверки доступности выполнен отдельный явный запрос; автоматического
  повтора не было. Сбой и успешный ответ сохранены в журнале.

Исходники доработанного приложения сохранены в `apps/server/integrations/buzha/`
и развёрнуты в `Y:\Приложения\Бужа`. Документация: `docs/buzha.md`.
Исходная версия приложения и затрагиваемых файлов сохранена в
`%TEMP%\snarkroute-buzha-20261027`; пользовательские заказы не удалялись.

Имеющиеся до начала работы изменения Tech Radar, CozyClay, H3, Секретаря и
прочие правки сохранены в рабочей копии и не включаются в коммит Бужи.
В частности, существующая вкладочная навигация ещё не была закоммичена:
строка `workshopTabs.agents.appIds` с `buzha` остаётся поверх этой работы.
Чистый базовый лаунчер отображает все карточки каталога и показывает Бужу
без этой навигации. Коммит интеграции сохраняет самостоятельную работоспособность.
Проверенная ветка Бужи сливается fast-forward в исходную
`build/2026-10-25-tech-radar`; незакоммиченная рабочая копия при этом сохраняется.

Первый штатный restart SnarkRoute упёрся в существующий `Graceful stop timeout`.
Проверенный по контроллеру и командной строке собственный API-процесс был
завершён адресно; контроллер успешно поднял замену. Следующий штатный restart
прошёл самостоятельно. Другие процессы не завершались.

Не реализованы: автопоиск, почта/Telegram, выполнение клиентских заказов,
кошелёк, расписание. Задания в UI — записи пользователя. Вопросы будущего
исполнителя должны направляться через Секретаря.
