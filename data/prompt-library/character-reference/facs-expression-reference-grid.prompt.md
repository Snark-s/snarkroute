Create a professional FACS-style facial expression reference grid for the character described below.

Use strict production continuity. The same character must remain identical across all panels unless a listed action explicitly requires a head or eye direction change. Preserve identity, facial structure, body proportions visible in frame, hairstyle or grooming, costume, accessories, markings, asymmetrical details, and overall visual style.

Render the output as a clean technical character-reference sheet with a neat grid layout on a simple light or white background. Use consistent studio lighting and consistent framing. Each panel should be clearly separated and should include a visible panel number and a short label. Make the numbering sequential and easy to read.

The sheet should function as an animator / rigger / expression-design reference, not as a glamour poster.

LAYOUT REQUIREMENTS:
- Arrange the sheet as a large clean grid, ideally 7 columns by 7 rows for 49 panels, unless a different count is requested.
- Keep most panels front-facing head-and-shoulders portraits.
- Use side or angled views only where required by the specific action, such as head turns or tilts.
- Keep the character centered in each panel.
- Show the panel number and a concise action label within or below each panel.
- Make the typography clean and readable.
- Avoid clutter, decorative backgrounds, or dramatic cinematic effects.

- If the user provides a custom action list, use that instead of the default panel set.
